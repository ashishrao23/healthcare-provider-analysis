# Dataset

This folder contains a 100-row sample of the healthcare provider dataset.

The sample allows visitors to inspect the dataset's structure and columns. The analysis and results in the main notebook were generated using the full dataset.

The complete CSV files are not included in this repository because of their size.

## Running the full analysis

Download the full dataset using the link below and place the required CSV files in the data folder.

Full dataset: [Download files]( https://drive.google.com/drive/folders/1c-Uu6Q1swRRcsVCYiaRT5jmoAolRjo6k?usp=sharing)

The sample alone will not reproduce the full project's results.
